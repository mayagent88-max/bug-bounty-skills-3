# Grow an X account safely within daily caps

## Audit the baseline first

- Record the follower count, the following count, and the post count before the daily round starts.

- Keep those three numbers in one note so later growth is measured against the same baseline.

- Compare each later count against that baseline before you report growth for the day.

## Stay inside the daily caps

- Cap posts at 2 to 3 per day and stop posting once you reach the cap.

- Cap likes at about 10 per day and spread them across the day.

- Cap replies at 5 per day and keep each reply on topic.

- Cap new follows at 3 to 5 per day and stop following once you reach the cap.

- Wait several minutes between actions instead of acting in a fast burst.

- Skip mass unfollows, bought followers, and bulk automation entirely.

- Post each text only once and never repeat the same text across posts.

- Skip link spam and keep links out of posts unless one link is the point of the post.

## Write posts as a personal take

- Write each post as a genuine personal take in your own words.

- Open with a short personal story or a real experience from your own work.

- Add one helpful tip the reader can use right away.

- Keep each post within 280 characters before you publish it.

- Write the project handle inside the post text when the post is about a project.

- Skip announcements, rank boasts, and link spam as post styles.

## Run the daily routine

- Publish one post each day from the personal take pattern above.

- Add a few likes and replies inside the daily caps after the post goes out.

- Send a short morning report that lists the follower count, the following count, the post count, and the link to each post published.

## Keep the account safe

- Read the account handle from your own memory or USER.md before you start work.

- Work only on that account and never act on an account that belongs to someone else.

- Open the saved browser session that is already logged in instead of signing in again.

- Avoid logging in with a username and password from a datacenter VM because that route gets blocked by IP.

- Skip the X API when the user says it costs too much.

## Keep the bio and profile honest

- Write a short bio that states honestly what the account does, such as airdrop hunting, early alpha, testnets, and whitelists.

- Treat a profile photo change and a banner change as separate steps from daily posting.

- Ask the user for approval before you change the profile photo or the banner.

## Websites

- [X](https://x.com/) for posting, replying, liking, and following from the saved logged in session. Carry the exact post text into the browser task and verify the post link after publishing.

## Alternatives for better results

- Grow through replies on large accounts in the same topic when your own posts get little reach, because a useful reply can bring new followers without an extra post.

- Ask the user for one topic they care about that week when ideas run dry, and build the daily posts around that topic instead of repeating old posts.
