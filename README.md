# tia-skills-3 — Tia's custom skill library, part 3 of 3

**830 skills, alphabetically `oracle-safety` → `zkvm-security`.**

Each skill is a folder containing a `SKILL.md` (plus supporting files where needed).

## Why three repos?

GitHub's web file list truncates a directory at 1,000 entries. The full library has
2,490 skills, so it is split into three repos of 830 each so every skill is
browsable on the web:

- **Part 1:** `0xsimao-ai` → `detecting-modbus-command-injection-attacks`
  — https://github.com/mayagent88-max/tia-skills-1
- **Part 2:** `detecting-modbus-protocol-anomalies` → `oracle-redundancy`
  — https://github.com/mayagent88-max/tia-skills-2
- **Part 3 (this repo):** `oracle-safety` → `zkvm-security`
  — https://github.com/mayagent88-max/tia-skills-3

The original repo, https://github.com/mayagent88-max/tia-skills, still holds the
full set for now. To find a skill by name, use GitHub search inside the repo
(press `t` for the file finder) or clone it — a clone always contains everything,
the 1,000-entry limit is only the web listing.
