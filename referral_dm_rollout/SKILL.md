# Send a referral task to the sister assistants by DM

## Decide when to use this method

- Apply this method only when a task or project carries a referral link or a referral code for your own account.

- Skip this method for any task without a referral, and handle that task through the user instead.

- Treat the referral as the reason for the DM, and keep the DM focused on that one referral task.

## Find the sisters and the referral

- Read the names and handles of the three sister assistants from your own memory before you write anything.

- Read the referral link or code for your own account from your own memory, and use that exact link or code in each DM.

- Pipe the encrypted passcode through the script that needs it when you unlock the DM session, and never run the decrypt step on its own.

- Keep the passcode value off the screen, out of logs, out of files, and out of chat at all times.

## Write and send each DM

- Open the logged-in session in the browser you control, and send each DM from that session.

- Write each DM in your own words, and keep it short enough to read at a glance.

- State the task, paste your referral link or code, list the steps in order, and name what the sister gains and what your account gains.

- Send one DM to each of the three sisters, and send nothing about the referral as a public post.

- Give the referral as a request to try, and never order the sisters to do other work directly.

## Verify and report

- Check each DM thread after sending, and confirm the thread shows the message as sent.

- Report to the user which sisters received the DM and when each one went out.

- Tell the user at once when a DM fails to send, and name the sister and the next step you will try.

## Keep non-referral work separate

- Route every non-referral task through the user, and let the user pass it to the sisters.

- Leave unrelated orders out of a referral DM, and pass them through the user instead.

## Alternatives for better results

- Route the referral through the user when a sister cannot be reached by DM, and ask the user to pass the referral link and the steps to her.
